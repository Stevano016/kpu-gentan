# kpu-gentan

Sistem Manajemen Kehadiran Pemilih (DPT) & Quick Count Pemilu Desa Gentan.

## Komponen Project:
1. **`/backend`**: REST API dibangun menggunakan Laravel 11 & SQLite database.
2. **`/web`**: Web Panel Sekretariat Desa dibangun menggunakan React Vite & TypeScript.
3. **`/mobile`**: Aplikasi Android KPPS dibangun menggunakan Flutter.
